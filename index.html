说明：类型判定有两种方式——未配置 AI 时用本机统计规则（看色彩、亮度、肤色占比、边缘纹理）， 这类方法分不清暖棕色场景与暖棕色动物，所以证据不足时会直接说「无法判断」而不是硬猜； 配置了视觉大模型后由模型做语义判断，准确得多。最终类型与风格仍以你的判断为准。 所有参数为起点区间，请以画面实际效果微调，不要一次拉到底。

新手怎么用？（30 秒看完）
  1. 上传照片后，先在「图片类型」里选对场景：人像修皮肤、风光修层次、COSER 修妆造、宠物修毛发。自动判断不准就手动点，一步都不耽误。
  2. 要让识别更准，在「识别方式」里配一个视觉大模型（填自己的 API Key，只存在本机浏览器）。配好之后类型由模型判断，连画面元素也会一起识别出来。
  3. 选一个风格，左侧预览会用近似滤镜给你看大致调性（不是最终效果，仅作方向参考）。
  4. 点「开始识别」，得到一份按顺序排好的 PS 参数表：项目 → 参数范围 → 作用区域 → 为什么这样调。
  5. 在 Photoshop 里照抄即可：影调先做（滤镜 › Camera Raw 滤镜 › 基本），颜色再做（HSL、曲线、分离色调），最后才是磨皮、锐化和导出。
