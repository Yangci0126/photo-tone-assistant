# 影调助手 · Photo Tone Assistant

面向摄影初学者的**修图建议生成器**。上传一张照片，选图片类型和目标风格，它会先做像素级分析，再输出一份**只基于 Photoshop 的、可照着点参数的修图方案**。

纯静态单页，无需后端、无需 API Key、无需构建，图片全程留在浏览器本地。

## 三步出结果

1. **上传图片** —— 拖拽或点选，支持 JPG / PNG / WebP / HEIC(视浏览器)
2. **选类型 + 选风格** —— 普通人物 / COSER / 自然风景，再从 15 个预设风格里挑一个
3. **点「开始识别」** —— 输出约 30 条分 6 组的具体建议

## 它不是随机生成建议

上传后会把图缩到长边 380px，在 Canvas 上做真实统计：

| 维度 | 用途 |
|---|---|
| 亮度直方图、p05/p95、暗部与高光裁切占比 | 判断曝光偏差、反差是否够、有没有死黑死白 |
| 明度标准差 | 反差强弱 |
| 平均饱和度、HSV 分布 | 判断色彩浓度、是否过饱和 |
| 边缘梯度密度 | 细节量 → 决定锐化和降噪力度 |
| 12×12 网格的**肤色连通块** | 估人数、定位面部区域 |
| 天空 / 植被 / 水面 / 中性墙面占比 | 场景元素判定，决定局部精修项 |
| 低饱和像素的 R−B 偏移 | 白平衡偏移方向 |

> 白平衡只用**低饱和像素**估计，而不是全图平均——否则大片暖色皮肤或绿色植被会把色温判断带偏。

最终产物是「图片类型 × 预设风格 × 实测指标」三方合成：指标负责**校正**，风格负责**创作倾向**，两者按偏差大小加权（偏差大时校正主导，偏差小时风格主导），避免双重提亮把画面洗白。

## 15 个预设风格

- **人像向**：日系清新、港风复古、干净人像、奶油柔光、甜酷霓虹、胶片感
- **风光向**：通透风光、暗调自然、森系自然、黑金夜景、国风
- **通用**：复古暖调、电影感、暖调、冷调

每个风格都带独立的影调目标、曲线形状、分离色调与 HSL 分组，选风格时左侧预览会用近似滤镜实时演示调性（非最终效果）。

## 输出长什么样

约 30 条建议，分 6 组，每条都是四段式：

```
曝光         +0.18 EV      全图      实测平均亮度 96/255，略微欠曝……
对比度       -6 ~ +6       全图      ……
色温         5300 ~ 5700 K 全图      ……
曲线         S 型中段 +8   全图      ……
```

分组顺序：**基础影调 → 色彩与白平衡 → 风格附加 → 类型专项 → 局部精修（蒙版）→ 细节与输出**，每组都标注了在 PS 里的路径。顶部另有 6 步执行顺序，新手照着走即可。

每条建议还带一个来源标签：

- `诊断` —— 来自你这张图的实测数据
- `风格` —— 来自你选的预设
- `类型` —— 来自场景类型

## 部署

静态站点，直接推 GitHub Pages：

```
Settings → Pages → Source: Deploy from a branch → main / (root) → Save
```

本地预览也可以直接双击 `index.html`（`file://` 下也能用，但更推荐起个本地服务）。

## 文件结构

```
index.html    页面结构
styles.css    暗房风格样式 + 移动端适配
app.js        像素分析 + 风格库 + 建议规则引擎
```

## 说明与边界

- 元素「识别」是基于**色彩 / 亮度 / 纹理的统计推断**，不是 AI 语义识别。所以它只提供「建议类型 + 置信度」，最终类型仍由你点选。
- 宠物类没有单独建类型（保持三类），但检测到「暖棕大面积 + 无明显肤色特征」时会追加毛发与眼睛的处理建议。
- 建议是**方向性参考**，具体数值请以你的原图和显示器为准，别盲抄。
