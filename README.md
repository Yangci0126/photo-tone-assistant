# 影调助手 · Photo Tone Assistant

面向摄影初学者的**修图建议生成器**。上传一张照片，选图片类型和目标风格，它会先做像素级分析，再输出一份**只基于 Photoshop 的、可照着点参数的修图方案**。

纯静态单页，无需后端、无需构建。默认零上传，图片全程留在浏览器本地；也可以选配一个视觉大模型来做语义识别。

## 三步出结果

1. **上传图片** —— 拖拽或点选，支持 JPG / PNG / WebP / HEIC(视浏览器)
2. **选类型 + 选风格** —— 普通人物 / COSER / 自然风景 / 宠物，再从 15 个预设风格里挑一个
3. **点「开始识别」** —— 输出约 30 条分 6 组的具体建议

## 它不是随机生成建议

上传后会把图缩到长边 380px，在 Canvas 上做真实统计：

| 维度 | 用途 |
|---|---|
| 亮度直方图、p05/p95、暗部与高光裁切占比 | 判断曝光偏差、反差是否够、有没有死黑死白 |
| 明度标准差 | 反差强弱 |
| 平均饱和度、HSV 分布 | 判断色彩浓度、是否过饱和 |
| 边缘梯度密度 | 细节量 → 决定锐化和降噪力度 |
| 12×12 网格的**肤色连通块** | 估人数、定位面部区域 |
| 毛色像素占比 + 毛色像素的平均亮度 | 宠物判定 / 黑毛·白毛·中性毛分档 |
| 中频纹理密度（26 < 梯度 ≤ 100 的占比，分中部与全局） | 毛发的核心特征：皮肤平滑、毛发毛糙 |
| 毛色 / 纹理的 12×12 **网格分布**（铺满度、最大连块、紧致度） | 区分「主体是一团」还是「整幅铺满」，挡住暖棕风光误判成宠物 |
| 天空 / 植被 / 水面 / 中性墙面占比 | 场景元素判定，决定局部精修项 |
| 低饱和像素的 R−B 偏移 | 白平衡偏移方向 |

> 白平衡只用**低饱和像素**估计，而不是全图平均——否则大片暖色皮肤或绿色植被会把色温判断带偏。

### 宠物类型怎么判的

颜色靠不住：暖色毛发几乎 100% 会被肤色判据命中（实测棕毛宠物 `skinPct = 99.7%`）。真正稳定的是**纹理**——皮肤的 `centerMid` 在 0.03 左右，毛发在 0.25 以上。

但只靠「毛色面积 × 纹理密度」会踩一个坑：**秋色树林、沙漠、岩壁、金色麦田**这类暖棕色满屏纹理的风光，指标和真宠物几乎一样。所以还加了两个止错机制：

**1. 空间分布判据。** 12×12 网格上统计毛色与中频纹理的分布，宠物是「中间一团 + 四周背景」，风光是「整幅铺满」：

| 指标 | 含义 | 宠物 | 满屏暖棕场景 |
|---|---|---|---|
| `coatSpread` | 毛色覆盖率 > 32% 的网格占比 | 0.15~0.35 | 0.8~1.0 |
| `coatMainPct` | 最大毛色连通块占全图比例 | 0.15~0.45 | 0.6~1.0 |
| `coatCompact` | 主块面积 / 毛色格子数 | 0.8~1.0 | 0.5~0.9 |

**2. 否决 + 说不准就不说。** 出现「天空 ≥8%」「植被 ≥12%」「毛色铺满 ≥60%」「最大毛色块 ≥52%」任一条，宠物分直接乘 0.30。三个类型分（人物 / 宠物 / 风光）取最高者，但**最高分低于 0.42 时不猜**，直接返回「无法判断，请手动选择」。同样地，置信度低于 0.55 不会自动勾选类型，只在提示里告诉你最接近哪个。

人像判定也加了纹理约束：皮肤是平滑的，中部纹理一旦超过阈值（`centerMid > 0.16` 左右）就不算「一张脸」——否则棕毛宠物会因为 `skinPct` 极高而被判成人像。

黑毛 / 白毛 / 中性毛不是看全图亮度，而是看**毛色像素自己的平均亮度**（`coatLum`），否则深色背景会把金毛判成黑毛。

> 这些约束能挡住绝大多数误判，但**暖棕色场景 vs 暖棕色动物在像素层面本就没有稳定差异**。真要判得准，得靠下面的 AI 识别。

## AI 识别（可选，自己带 Key）

本地统计法做不到的事，交给视觉大模型。点「识别方式 → 配置 AI」，填自己的 API Key 即可，支持任何 OpenAI 兼容的视觉接口：

| 预设 | Base URL | 建议模型 |
|---|---|---|
| 火山方舟（豆包） | `https://ark.cn-beijing.volces.com/api/v3` | 接入点 ID（`ep-` 开头）或 `doubao-1.5-vision-pro-32k-250115` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| 阿里云百炼 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-vl-max-latest` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4v-flash`（有免费额度） |
| 自定义 | 任意 OpenAI 兼容地址 | 任意视觉模型 |

配置后，识别时会先把图压到长边 1024 交给模型，让它返回类型、置信度、关键元素和一句判断理由。模型结果会写进结果区的「AI 判定 / AI 识别元素 / AI 判断依据」三张卡，也会进导出的 TXT。模型调用失败时自动回退本地规则，不会卡住流程。

**关于隐私**：Key 存在浏览器的 `localStorage` 里，不写进任何代码、不发往除你指定服务商以外的地方。配置后图片会发送给该服务商，页面顶部提示会从「🔒 默认零上传」变成「📤 已接 AI」。

最终产物是「图片类型 × 预设风格 × 实测指标」三方合成：指标负责**校正**，风格负责**创作倾向**，两者按偏差大小加权（偏差大时校正主导，偏差小时风格主导），避免双重提亮把画面洗白。

## 15 个预设风格

- **人像向**：日系清新、港风复古、干净人像、奶油柔光、甜酷霓虹、胶片感
- **风光向**：通透风光、暗调自然、森系自然、黑金夜景、国风
- **通用**：复古暖调、电影感、暖调、冷调

每个风格都带独立的影调目标、曲线形状、分离色调与 HSL 分组，选风格时左侧预览会用近似滤镜实时演示调性（非最终效果）。

## 输出长什么样

约 30 条建议，分 6 组，每条都是四段式：

```
曝光         +0.18 EV      全图      实测平均亮度 96/255，略微欠曝……
对比度       -6 ~ +6       全图      ……
色温         5300 ~ 5700 K 全图      ……
曲线         S 型中段 +8   全图      ……
```

分组顺序：**基础影调 → 色彩与白平衡 → 风格附加 → 类型专项 → 局部精修（蒙版）→ 细节与输出**，每组都标注了在 PS 里的路径。顶部另有 6 步执行顺序，新手照着走即可。

每条建议还带一个来源标签：

- `诊断` —— 来自你这张图的实测数据
- `风格` —— 来自你选的预设
- `类型` —— 来自场景类型

## 说明与边界

- **类型判定**分两条路：未配置 AI 时用本机统计规则（色彩 / 亮度 / 纹理 / 空间分布），配置后用视觉大模型做语义判断。
- 统计规则**分不清「暖棕色树林」和「暖棕色猫」**——这两者在像素层面几乎同分布。所以它会在证据不足时说「无法判断」，而不是硬猜一个相近的类型。想稳定准确，请配 AI 识别。
- 反过来，**白毛宠物配浅色背景**（白猫趴在白沙发）本地规则也常常判不出来，同样建议走 AI 或手动选。
- 结果区的特征卡片是**本地像素统计，不是 AI 的结论**，卡片名称会跟着判定类型走：只有判成宠物时才叫「毛发 / 毛色块」「毛色纹理密度」，其他类型显示为「暖色块占比」「纹理密度」。风景里这两项偏高是正常的（落叶、土壤、岩石、枝叶都是高暖色 + 高纹理），不影响类型判定，必要时卡片下方会附一句出处说明。
- 类型专项的文案同样跟随类型：风光方案里不会出现磨皮、主体径向打光这类人像操作，橙色 HSL 的说明也从「肤色 / 毛发」换成「落叶 / 岩石 / 木石」。
- 建议是**方向性参考**，具体数值请以你的原图和显示器为准，别盲抄。

## 更新记录

### v1.1 · 参数一致性修复

问题都出在同一个地方：参数来自三条独立的生成路径（实测校正 / 风格预设 / 类型专项），同一个滑块会被写两三遍，读者拿到的是互相对不上的区间。

- **同一滑块只给一次**。按项目名合并，保留最贴近实测的一条，其余丢弃并在说明里注明「已合并，只按这里调一次」。修改前一张风光图会给出 `去朦胧 -6 ~ +4` 和 `去朦胧 +8 ~ +16` 两套数值，修改后只剩一条。
- **去朦胧改成图像判断**。画面不在发灰区间时不再给正值——通透感靠压高光和提暗部拿到，靠去朦胧硬拉只会出脏边和光晕。
- **高光恢复不再另开一套区间**。改为引用基础影调已经压到的值，只在「压完仍救不回层次」时给下探路径（-60 ~ -90），并要求用渐变蒙版只压天空；白色阶不再重复压。
- **区域名跟着类型走**。风景方案里不再出现「额头 / 头发」，宠物方案里不再出现「皮肤 / 头发」。
- **导出长边按原图封顶**。原图长边 4032px 时不会再让你导出 4096px（插值放大只会变糊），执行顺序里的那一条也跟着变。
- **天空压暗只给一次**。风景的「渐变滤镜 · 天空」和通用「天空蒙版」不再重复出现。
